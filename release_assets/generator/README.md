# Ruflet Explorer release artwork

This Next.js generator produces the final Ruflet Explorer store artwork.

The phone release set contains four upright screenshots:

1. Home — Ruby Anywhere
2. Gallery — Explore Every Example
3. SpinKit — Beautiful Loading States
4. Charts — Charts That Come Alive

Targets:

- Apple App Store: iPhone 6.9-inch, 1320×2868
- Google Play: Android phone, 1080×1920
- Google Play feature graphic: 1024×500

Run the generator:

```bash
bun dev
```

Build verification:

```bash
bun run build
```
